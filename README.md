# ACCELA - Repositório de Backup (Código Fonte Estável)
Aviso: Este repositório é apenas um backup das versões estáveis do projeto original ciscosweater/enter-the-wired. Ele não é um fork ativo para desenvolvimento, mas sim um ponto de preservação de integridade do código.

Propósito
Manter a integridade do código fonte original de versões estáveis.

Servir como contingência caso o software original seja descontinuado ou sofra problemas de compatibilidade.

Garantir que seja possível executar o sistema mesmo com mudanças no formato de distribuição oficial.

Diferença de versão
A numeração de versão presente neste repositório foi modificada para indicar claramente que o código não foi obtido diretamente do repositório oficial e sim deste backup. Exemplo: 20260521220000-backup.

Sobre os formatos disponíveis
Diferente da versão oficial mais recente (ex: 20260512222534), que distribui o programa apenas em formato AppImage, aqui estão disponíveis: código fonte em Python, executável .AppImage e executável .exe para Windows.

Estrutura mantida
Pasta src/ com o código fonte original

run.sh e requirements.txt

Nenhuma alteração funcional no código — apenas preservação e alteração do identificador de versão.

Créditos
Todo o crédito do projeto original pertence a ciscosweater. Nenhuma modificação lógica foi feita no código.

🇺🇸 English
ACCELA - Backup Repository (Stable Source Code)
Notice: This repository is intended solely as a backup of stable versions of the original project ciscosweater/enter-the-wired. It is not an active development fork, but rather a preservation point for code integrity.

Purpose
Maintain the integrity of the original stable source code.

Serve as a contingency in case the original software is discontinued or suffers compatibility issues.

Ensure the system remains executable even after changes in the official distribution format.

Versioning
The version number in this repository has been modified to clearly indicate that the code was not obtained directly from the official repository but from this backup. Example: 20260521220000-backup.

About the available formats
Unlike the most recent official version (e.g., 20260512222534), which distributes the program only in AppImage format, here you will find: Python source code, .AppImage executable, and .exe executable for Windows.

Maintained structure
src/ folder with the original source code

run.sh and requirements.txt

No functional changes to the code — only preservation and version identifier change.

Credits
All credit for the original project goes to ciscosweater. No logical modifications were made to the code.
